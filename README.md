# WordPress GEOInflow Analytics

独立 WordPress 插件，用于连接自托管 GEOInflow，展示本站统计、注入浏览统计脚本和同步公开内容目录。与 GEOFlow 内容工作台独立。

## 0.3.0 功能

- WordPress 后台新增「GEOInflow 统计」，按今天、近7天、近30天查看 PV、访客、访问和跳出访问。
- 服务端查询 GEOInflow `/api/websites/{UUID}/stats`，先核对当前 WordPress 域名，不向浏览器发送平台凭据。
- 连接测试、公开内容目录手动和可选定时同步；密码用 WordPress salt 派生密钥加密保存。
- 统计脚本全站注入；已有 `geoinflow-tracker.php` MU 插件时跳过，避免重复。
- 服务器/Cloudflare/手动日志接入引导使用对应平台入口。插件不执行 root 命令。

## 安装

将安装包上传到 WordPress → 插件，启用后在「设置 → 前程 GEO 连接器」填写平台 HTTPS 地址、网站 UUID 和专用账号。先测试连接，再同步目录并核对平台实际结果。后台「GEOInflow 统计」读取本站数据。需要 WordPress 5.9+、PHP 7.4+ 和 OpenSSL。

## 状态与限制

这是开发预览版本，PHP 语法检查通过；尚未完成真实 WordPress 功能和视觉验证、部署版接口兼容性测试、真实目录同步及两站安装验收。不要将安装或连接成功视为采集完成。

- 基础统计读取以 WordPress 站点时区为准，无数据、未提供和请求错误分别处理；不重建统计算法。
- 页面主题需正确调用 wp_head；静态页面、CDN缓存、广告拦截等可能改变采集覆盖。
- 同步只发送公开URL、标题、类型及时间，不发送正文、私密内容或用户数据；最多5000条、每批500条。接口采用 upsert，下线URL不自动从平台删除。
- WP-Cron 依赖访问；不保证低流量站准时同步。启用二次验证的账号当前不支持密码自动连接，不应为此关闭二次验证。
- 看板目前仅包含基础汇总；趋势、来源、页面排行、AI引荐和日志状态仍在完整平台查看。
- 服务器日志采集器独立运行；安装插件不代表服务器采集器已配置。不默认保留访问者原始数据到WP数据库。
